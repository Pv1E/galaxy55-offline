# Anomalia Invisible (anadido del port, como los Invisibles de Kube): un cubo de 4x4x4, 8 Cofres de Kube envueltos en Kubes
# invisibles, flotando sobre el terreno. Los Kubes invisibles pintan el cielo de detras; a traves de la vitre blindee teintee
# o de la glace noire se ven como bajo una luz negra (aristas azules). Pasar por debajo identifica la anomalia.
# uso: devrun.ps1 -Script port/dev/anomalia_invisible.txt -Extra "--lang=fr --seed=55"
# semilla 55, otono, tamano 1 (generador version 1: la Invisible es su unica anomalia). Las coordenadas van respecto a la
# anomalia (find anomaly invisible: fx fy = el centro del cubo, fz = lo alto del cubo)
wait 3
kub forget
print kub
find anomaly invisible
# desde abajo, contra el cielo: no se ve (y se identifica: aviso arriba a la derecha)
tp fx+5.5 fy+6.5 top
lookat fx fy fz-1
wait 39
shot invisible_dessous
print kub
# desde arriba, con el suelo detras: un cubo de cielo
set fx fy+7 fz+15 BRock
tp fx+0.5 fy+7.15 fz+16
lookat fx+0.5 fy+0.5 fz-1
wait 20
shot invisible_dessus
# a traves de la vitre blindee teintee (un suelo de 3x3 entre la camara y el cubo)
set fx-1 fy+4 fz+13 BShipGlassBlack
set fx fy+4 fz+13 BShipGlassBlack
set fx+1 fy+4 fz+13 BShipGlassBlack
set fx-1 fy+5 fz+13 BShipGlassBlack
set fx fy+5 fz+13 BShipGlassBlack
set fx+1 fy+5 fz+13 BShipGlassBlack
set fx-1 fy+6 fz+13 BShipGlassBlack
set fx fy+6 fz+13 BShipGlassBlack
set fx+1 fy+6 fz+13 BShipGlassBlack
wait 20
shot invisible_vitre
# a traves de la glace noire
set fx-1 fy+4 fz+13 BBlackIce
set fx fy+4 fz+13 BBlackIce
set fx+1 fy+4 fz+13 BBlackIce
set fx-1 fy+5 fz+13 BBlackIce
set fx fy+5 fz+13 BBlackIce
set fx+1 fy+5 fz+13 BBlackIce
set fx-1 fy+6 fz+13 BBlackIce
set fx fy+6 fz+13 BBlackIce
set fx+1 fy+6 fz+13 BBlackIce
wait 20
shot invisible_glace
set fx-1 fy+4 fz+13 none
set fx fy+4 fz+13 none
set fx+1 fy+4 fz+13 none
set fx-1 fy+5 fz+13 none
set fx fy+5 fz+13 none
set fx+1 fy+5 fz+13 none
set fx-1 fy+6 fz+13 none
set fx fy+6 fz+13 none
set fx+1 fy+6 fz+13 none
# un hueco de 2x2 arriba: se ven los cofres de debajo (aunque sigan tocando Kubes invisibles por los lados)
set fx-1 fy-1 fz none
set fx fy-1 fz none
set fx-1 fy fz none
set fx fy fz none
# un bloque pegado al cubo se sigue viendo: la invisibilidad no pasa a lo que toca
set fx+2 fy-1 fz-1 BWood
wait 20
shot invisible_ouvert
# Base de datos ESCorp
kub got BKubeInvisible
kub got BKubeChest
kub
wait 3
kub pick BKubeInvisible
wait 2
shot invisible_kub_ficha
kub page 2
wait 2
shot invisible_kub_cat
kub tab 1
wait 2
kub nav 0 28
wait 2
shot invisible_kub_espacio
kub close
print kub
quit
